# -Landing-Page-Banda-de-Rock

Landing page for a rock band that wants to promote its identity, music, and upcoming events. 
The goal is to convey energy, style, and personality, capturing the attention of potential concertgoers.

## How to see it

1. Download or clone this repository
2. Open the `index.html` file in your web browser
3. Done! You can now view the site

## Technologies I Used

- HTML
- CSS (with responsive design)
- JavaScript
